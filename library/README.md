## Setup
    pip install -r requirements.txt
    python3 app.py
    # -> http://localhost:5000

- GET /api/books
- GET /api/books/<id>
- GET /api/books/<id>/chapters
- GET /api/books/<id>/bookmarks   
- GET /api/search?title=<query>
